# C# Projects: Tetris & Advanced Calculator 🎮🧮

A collection of C# desktop applications built to practice Object-Oriented Programming (OOP) concepts and algorithm design.

## 📂 Projects Included
* **Tetris:** A clone of the classic game, focusing on grid-based logic, piece rotation, and line-clearing algorithms.
* **Advanced Calculator (Gelişmiş Hesap Makinesi):** A calculator application capable of handling complex mathematical operations and UI logic.

## 🛠️ Technologies Used
* C#
* .NET Framework
* Windows Forms Application
